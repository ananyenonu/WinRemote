# Security Policy

## Supported versions

Security fixes are intended for the latest released version.

## Reporting a vulnerability

Please do not publish exploit details or credentials in a public issue. Until a private security contact is configured for this repository, contact the maintainer through GitHub's private vulnerability reporting feature if enabled.

## Deployment guidance

- Use WinRemote only on a trusted private network.
- Never port-forward its port or expose it directly to the public internet.
- Keep the pairing code, browser session token, CA private key, and runtime state private.
- Install only the CA certificate generated by your own Windows installation.
- Do not commit runtime state, private keys, certificates, logs, or local environment files.
- WinRemote controls local input. Treat access to a paired device as equivalent to physical access to the logged-in desktop.
