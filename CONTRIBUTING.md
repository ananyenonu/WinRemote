# Contributing

Thanks for considering a contribution to WinRemote.

1. Open an issue describing the bug or proposed change before large changes.
2. Keep changes focused and explain the user-visible impact.
3. Do not add telemetry, cloud relays, credential collection, or internet-facing listeners without explicit discussion and security review.
4. Never commit pairing codes, session tokens, private keys, certificates, logs, or local state.
5. Run `python -m py_compile server.py` after backend changes and validate frontend JavaScript before submitting.
6. Include Windows version, Python version, phone/browser, and reproducible steps in bug reports. Redact IPs and all credentials.

By submitting a contribution, you agree that it may be distributed under the project's MIT License.
